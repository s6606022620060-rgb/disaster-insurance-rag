# เงินเยียวยาผู้ประสบภัยน้ำท่วมของกรุงเทพมหานคร (ปรับเพิ่ม)

แหล่งที่มา: แนวหน้า "ประกันภัยพิบัติมีผลแล้ว คุ้มครองทันที 30 ล.ครัวเรือนทั่วปท. กทม.เพิ่มเงินเยียวยา" (2 ต.ค. 2569 ปรับปรุง 7 ต.ค. 2569) อ้างอิงผู้ว่าราชการกรุงเทพมหานคร และรองผู้ว่าราชการกรุงเทพมหานคร
ข้อมูล ณ วันที่: 7 ตุลาคม 2569

## ภาพรวม

กรุงเทพมหานครปรับเพิ่มวงเงินช่วยเหลือผู้ประสบภัยน้ำท่วมในพื้นที่กรุงเทพฯ และเปิดรับคำร้องตั้งแต่วันที่ 2 ตุลาคม 2569 เป็นต้นไป พื้นที่ที่ประกาศเป็นพื้นที่ประสบสาธารณภัยมี 38 เขต 118 แขวง และสามารถเสนอขอประกาศเพิ่มเติมได้

## รายการเยียวยาและวงเงินที่ปรับใหม่

| รายการ | อัตราเดิม | อัตราใหม่ |
|---|---|---|
| ค่าวัสดุซ่อมแซมบ้าน (กรณีเสียหายทั้งหลัง) | 49,500 บาท | 88,600 บาท |
| ค่าเครื่องมือประกอบอาชีพ | 11,900 บาท | 13,500 บาท |
| ค่าจัดการศพผู้เสียชีวิต | - | 35,700 บาท |
| ค่าที่พักชั่วคราว | - | 3,000 บาทต่อเดือน สูงสุด 2 เดือน |
| ค่ารักษาพยาบาลผู้ป่วยนอก | - | 2,000 บาท |
| ค่ารักษาพยาบาลผู้ป่วยใน | - | 4,000 บาท |
| เงินปลอบขวัญผู้บาดเจ็บ | - | 2,300 บาท |

## วิธียื่นคำร้องในกรุงเทพฯ

- ยื่นออนไลน์ได้ โดยระบบเปิดตั้งแต่ช่วงเย็นวันศุกร์ที่ 2 ตุลาคม 2569 ไม่ต้องเดินทางไปสำนักงานเขต
- ยังสามารถยื่นที่สำนักงานเขตได้ตามปกติ
- ไม่ต้องใช้ใบแจ้งความจากสถานีตำรวจ
- กรุงเทพมหานครอยู่ระหว่างหารือเพื่อลดเอกสารประกอบให้เหลือเฉพาะที่จำเป็น

## ความสัมพันธ์กับประกันภัยพิบัติแห่งชาติ

ระบบประกันภัยพิบัติแห่งชาติครอบคลุมบ้านเรือนในกรุงเทพมหานครด้วย สำหรับภัยที่เกิดตั้งแต่วันที่ 1 ตุลาคม 2569 ส่วนเงินเยียวยาของกรุงเทพมหานครเป็นการช่วยเหลือของทางราชการตามระเบียบ ผู้ประสบภัยในกรุงเทพฯ สามารถสอบถามเพิ่มเติมได้ที่สายด่วนกรุงเทพมหานคร 1555
